# win-emotion-cam 开发说明

## 项目概述

win-emotion-cam 是一个 Windows 平台下的摄像头实时情绪识别工具。通过调用本地摄像头获取图像，利用深度学习模型分析图像中人物的情绪，并给出对应的沟通语气建议。

## 技术架构

### 核心技术栈

| 技术 | 用途 |
|------|------|
| Python 3.8+ | 运行环境 |
| OpenCV | 摄像头捕获、图像处理 |
| FER / DeepFace | 情绪识别模型 |
| NumPy | 数值计算 |
| FastAPI | REST API 服务 |

### 模块结构

```
win_emotion_cam/
├── __init__.py      # 包导出
├── model.py         # 情绪识别模型
├── detector.py      # 检测器封装
└── camera.py        # 摄像头捕获
```

## 核心模块

### 1. 摄像头模块 (camera.py)

负责摄像头的基本操作。

```python
from win_emotion_cam.camera import Camera

# 创建摄像头对象
camera = Camera(camera_index=0)  # 0 是默认摄像头

# 打开摄像头
if camera.open():
    # 读取单帧
    frame = camera.read()
    
    # 或使用生成器读取视频流
    for frame in camera.get_frames():
        # 处理每一帧
        pass
    
    # 释放资源
    camera.release()
```

**主要类和方法：**

- `Camera(camera_index)`: 初始化摄像头
- `open()`: 打开摄像头
- `read()`: 读取单帧图像
- `get_frames()`: 获取视频流生成器
- `release()`: 释放资源

### 2. 模型模块 (model.py)

负责情绪识别模型的管理和推理。

```python
from win_emotion_cam.model import create_model

# 创建模型 (可选 'fer' 或 'deepface')
model = create_model(backend='fer')

# 检测单帧图像
result = model.detect(frame)

print(result['emotion'])        # 'happy'
print(result['emotion_cn'])     # '开心'
print(result['confidence'])     # 0.89
print(result['tone'])           # '轻松、热情'
```

**支持的情绪类型：**

| 英文 | 中文 | 建议语气 |
|------|------|----------|
| happy | 开心 | 轻松、热情 |
| sad | 悲伤 | 温和、耐心、倾听 |
| angry | 愤怒 | 冷静、平和、避免对抗 |
| surprised | 惊讶 | 平稳、确认信息 |
| fearful | 恐惧 | 安抚、温柔、支持 |
| disgusted | 厌恶 | 尊重、保持距离 |
| neutral | 中性 | 自然、专业 |

### 3. 检测器模块 (detector.py)

整合摄像头和模型，提供高层 API。

```python
from win_emotion_cam import create_detector

# 创建检测器
detector = create_detector(
    camera_index=0,    # 摄像头索引
    model_backend='fer', # 模型后端
    fps_limit=5        # 限制帧率
)

# 启动
detector.start()

# 检测 (会自动从摄像头读取)
result = detector.detect()

# 运行主循环 (带 GUI 窗口)
detector.run_loop()

# 停止
detector.stop()
```

## 使用方式

### 方式一：独立运行（推荐）

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

可选参数：
- `-c, --camera`: 摄像头索引，默认 0
- `-m, --model`: 模型后端，默认 fer
- `-f, --fps`: 检测帧率，默认 5

示例：
```bash
python main.py -c 0 -m fer -f 5
```

### 方式二：API 服务

```bash
# 启动 API 服务
python api_server.py
```

服务启动后访问：
- API 地址: http://localhost:8000
- API 文档: http://localhost:8000/docs

### 方式三：作为模块调用

```python
from win_emotion_cam import create_detector

detector = create_detector()
detector.start()

# 获取实时结果
for frame in detector.camera.get_frames():
    result = detector.detect(frame)
    print(result['emotion_cn'], result['tone'])
```

## 模型选择

### FER (Fast Emotion Recognition)

- **优点**: 速度快，实时性好，资源消耗低
- **缺点**: 精度略低于 DeepFace
- **适用**: 实时应用、边缘设备

```python
model = create_model(backend='fer')
```

### DeepFace

- **优点**: 精度高，支持多种人脸分析任务
- **缺点**: 速度较慢，资源消耗高
- **适用**: 需要高精度的离线分析

```python
model = create_model(backend='deepface')
```

## 常见问题

### 1. 摄像头无法打开

- 检查摄像头是否被其他程序占用
- 尝试更换摄像头索引 `camera_index=1`
- 确保已安装 OpenCV: `pip install opencv-python`

### 2. 模型加载失败

- 确保已安装依赖: `pip install -r requirements.txt`
- FER 库需要 dlib: `pip install dlib`
- DeepFace 需要 TensorFlow 或 PyTorch

### 3. 识别效果不好

- 确保光线充足
- 脸部正对摄像头
- 尝试切换模型后端
- 调整帧率限制 `fps_limit`

## 开发指南

### 添加新的情绪映射

修改 `model.py` 中的 `TONE_MAP` 字典：

```python
TONE_MAP = {
    'happy': '轻松、热情',
    # 添加新的映射
    'your_emotion': '你的语气建议',
}
```

### 添加新的模型后端

1. 在 `model.py` 中添加加载逻辑
2. 实现 `detect()` 方法
3. 在 `EMOTION_MAP` 中添加情绪名称

## 性能优化

1. **降低帧率**: 使用 `fps_limit` 参数
2. **使用轻量模型**: 选择 FER 而非 DeepFace
3. **图像预处理**: 缩放图像尺寸
4. **批处理**: 积累多帧后批量处理
